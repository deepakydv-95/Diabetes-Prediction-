# 🩺 Diabetes Prediction using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict whether a patient is likely to have diabetes based on medical and demographic features.

The project uses the **Pima Indians Diabetes Dataset**, a binary classification dataset containing 768 records, 8 predictor variables, and one target variable called `Outcome`. The target contains `0` for no diabetes and `1` for diabetes.

> **Note:** This project is created for educational and machine learning demonstration purposes. It should not be used as a medical diagnostic tool.

---

## 🎯 Objective

The main objective of this project is to:

* Analyze the diabetes dataset
* Clean and preprocess the data
* Perform Exploratory Data Analysis
* Identify important patterns and relationships
* Train machine learning classification models
* Evaluate model performance
* Predict diabetes outcomes for new observations

---

## 📊 Dataset

The dataset contains the following features:

| Feature                  | Description                   |
| ------------------------ | ----------------------------- |
| Pregnancies              | Number of times pregnant      |
| Glucose                  | Plasma glucose concentration  |
| BloodPressure            | Diastolic blood pressure      |
| SkinThickness            | Triceps skin-fold thickness   |
| Insulin                  | 2-hour serum insulin          |
| BMI                      | Body Mass Index               |
| DiabetesPedigreeFunction | Diabetes pedigree function    |
| Age                      | Age in years                  |
| Outcome                  | 0 = No Diabetes, 1 = Diabetes |

The dataset contains 768 observations, with 500 records in class `0` and 268 records in class `1`.

## 🧹 Data Preprocessing

Some variables contain zero values that can represent missing or biologically implausible measurements. Therefore, zero values in:

* Glucose
* BloodPressure
* SkinThickness
* Insulin
* BMI

were treated as missing values and replaced using the median of the corresponding feature.

The `Pregnancies` column was not treated this way because zero pregnancies is a valid value.

## 🤖 Machine Learning Models

The project compares multiple classification algorithms:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors
5. Support Vector Machine

Logistic Regression is used as the primary baseline model because the target variable is binary.

---

## 📈 Model Evaluation

The models are evaluated using:

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
* ROC-AUC

The project does not hard-code a model accuracy because the final performance depends on the exact preprocessing, train-test split, model configuration, and execution environment.
